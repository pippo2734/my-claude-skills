# 識学×ホスピタリティ 返信文作成スキル

識学の「完全結果」「誤解なし」を軸にしながら、相手への敬意と歩み寄りを感じさせる文章を作成するスキル。

## 発動条件

以下のキーワードが含まれる場合に発動：
- 返信文、返信、メール、メッセージ、連絡、報告、依頼文、お願い

## 基本方針

### 識学の原則（絶対に守る）

1. **完全結果を明示する**
   - 「いつまでに」「何を」「どの状態にするか」を曖昧にしない
   - 「なるべく早く」「できれば」などの曖昧表現は使わない
   - 期限・成果物・完了条件を具体的に書く

2. **誤解（ゴカイ）を発生させない**
   - 解釈の余地を残さない
   - 「〜と思います」ではなく「〜です」と断定する
   - 条件分岐がある場合は明確に場合分けする

3. **位置（イチ）を意識する**
   - 相手との上下関係を踏まえた言葉遣い
   - 依頼なのか指示なのか報告なのかを明確に

### ホスピタリティの原則（冷たさを和らげる）

1. **感謝・労いを入れる**
   - 冒頭か末尾に相手への感謝や配慮の一言を添える
   - 例：「お忙しいところ恐れ入りますが」「いつもありがとうございます」

2. **理由・背景を簡潔に添える**
   - なぜその期限なのか、なぜその依頼なのかを一文で説明
   - 相手が納得しやすくなる

3. **相手の立場を想像した一文**
   - 「ご負担をおかけしますが」「急なお願いで恐縮ですが」など
   - ただし言い訳にはしない

## 出力フォーマット

ユーザーの要望に応じて以下から選択：

### 1. コピペ用（デフォルト）
```
---
【返信文】
---
{作成した返信文をそのままコピペできる形で出力}
---
```

### 2. Obsidian保存用
ユーザーが「保存して」「記録して」と言った場合、以下の場所に保存：
`04_Archive(記録・DB)/02_ログ・購入履歴/` 配下に日付付きファイル名で保存

```markdown
---
title: "[相手/件名]への返信"
created: YYYY-MM-DD
type: 返信文
to: 相手名
---

# 返信文

{作成した返信文}

# 補足メモ

- 背景：
- 完全結果：
```

## 作成手順

1. **情報収集**: ユーザーから以下を確認（不足していれば質問）
   - 誰に送るか（上司/部下/クライアント/同僚）
   - 何についての返信か
   - 伝えたい結果・依頼・報告内容
   - 期限や条件があるか

2. **完全結果の特定**: 「この返信で相手に何をしてもらいたいか」を明確化

3. **文章構成**:
   - 冒頭：感謝または挨拶（1文）
   - 本題：完全結果を明確に（期限・成果物・条件）
   - 背景：なぜかを簡潔に（1〜2文、必要な場合）
   - 締め：配慮の一言 + 明確な依頼

4. **チェック**:
   - 曖昧表現がないか
   - 相手が「で、何すればいいの？」とならないか
   - 冷たすぎないか

## 例

### 入力
「部下に今週金曜までにレポート出してほしい。先週も遅れたから今回はちゃんと出してほしい」

### 出力
```
---
【返信文】
---
お疲れさまです。

週次レポートの件、今週金曜（1/31）17:00までに提出をお願いします。

確認事項の整理に時間がかかる場合は、木曜中に一度途中経過を共有してください。
そうすれば金曜の最終版に向けて調整ができます。

よろしくお願いします。
---
```

**ポイント**：
- 「先週も遅れた」という過去の話は入れない（誤解・感情を生む）
- 期限を具体的に（金曜17:00）
- 困った場合の対処法も提示（ホスピタリティ）
- 完全結果：金曜17:00にレポート提出
